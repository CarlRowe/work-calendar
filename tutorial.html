从零制作一个网页应用 · 完整教程

以今天做的「工作排班表」为例，手把手讲清楚：一个网站是怎么从 0 到 1 做出来并上线的。

0先搞懂 3 个概念（不慌，很简单）

做一个能在网上打开的网页，只需要三样东西：

① 网页代码一个 .html 文件
（就是"网页本身"）
＋
② 数据库存数据的"云仓库"
（这样数据不丢、能共享）
＝
③ 托管平台给网页一个"网址"
（让大家能访问）
概念大白话今天用的工具要钱吗
网页代码描述"页面长什么样、怎么操作"的一堆文字写一个 index.html 文件免费
数据库一个云端仓库，把排班、假期、用户这些数据存在里面Supabase免费额度够用
托管平台把网页文件放到网上，生成一个能访问的网址GitHub Pages免费

💡 记忆口诀：网页代码是"房子"，数据库是"仓库"，托管平台是"门牌号+摆放位置"。三者齐了，网站就活了。

1准备账号（只做一次）

  1. GitHub：打开 github.com 注册。它是全球最大的代码托管网站，我们用它来存放网页文件，并提供免费域名。
  2. Supabase：打开 supabase.com，用 GitHub 账号一键登录（不用重新注册）。它是免费云数据库，存我们的排班数据。

2写网页代码（核心，其实也最简单）

网页代码是一个文本文件，扩展名是 .html。它里面一般包含三部分：

  • HTML：决定"页面上有哪些东西"（日历格子、按钮、输入框）
  • CSS：决定"这些东西长什么样"（颜色、大小、排版）
  • JavaScript：决定"这些东西怎么动"（点按钮弹出选项、改排班、保存数据）

这三部分可以写在同一个 .html 文件里，所以最终只需要 一个文件，非常方便携带和上传。

<!DOCTYPE html>
<html>
<head>
  <style> /* 这里写样式：颜色、大小 */ </style>
</head>
<body>
  <!-- 这里写内容：日历、按钮 -->
  <script> /* 这里写逻辑：点击、保存 */ </script>
</body>
</html>

✅ 今天的情况：这个"工作排班表"的代码就是豆包帮你写好的，保存在你的电脑上（文件名 index.html）。你不需要会写代码——把需求告诉 AI，代码就出来了。

3在数据库里建好"表格"（一次搞定）

网页要存数据，得先在 Supabase 里建一个"表格"，就像 Excel 里建一个工作表。我们的表叫 user_settings，专门用来存：

  • 每个用户的名字、是不是管理员
  • 每个人的值班锚点（哪一天开始上班）
  • 剩余假期天数
  • 每天手动改过的排班状态
  1. 登录 Supabase → 左上角点 New project 新建项目（随便起个名、选个地区）
  2. 左侧菜单选 SQL Editor（SQL 编辑器）
  3. 点 New query，把建表代码粘贴进去，点 Run 运行
  4. 看到"Success"就是建好了
-- 这是一段"建表代码"，运行一次即可
create table user_settings ( ... );
-- 表示：允许任何人（不用登录）读和写这张表，实现共享
-- 再插入一行：管理员"罗泽朝"，值班锚点 2026-09-03，假期 14 天

💡 为什么要"免登录"？我们给表开了"匿名读写权限"，这样任何人打开网页就能直接看到、修改数据，不需要注册账号——这就是今天你要求的"不用登录飞书/豆包也能用"。

4把"网页"和"数据库"连接起来

网页代码里需要"告诉"数据库：我的数据库在哪个网址、用什么钥匙访问。这两样东西叫：

  • Project URL：数据库的"地址"（形如 https://xxxx.supabase.co）
  • anon public key：数据库的"公开钥匙"（一长串字符，只发公开的这把，别发 service_role 那把）

这两样在 Supabase 的 Project Settings → API 里能找到。把它们填进网页代码开头的位置，网页就知道去哪儿存取数据了。

// 网页代码最开头，类似这样（示意）
const SUPABASE_URL = "https://你的项目.supabase.co";
const SUPABASE_KEY = "eyJ...一长串公开钥匙";

5把网页上传到 GitHub 并开启网站

  1. 建仓库：GitHub 首页右上角 + → New repository → 起名（如 work-calendar）→ 选 Public → 创建
  2. 上传文件：进入仓库，地址栏打开 https://github.com/你的用户名/仓库名/upload → 把 index.html 拖进去 → Commit changes
  3. 开启 Pages：仓库 Settings → 左侧 Pages → Source 选 Deploy from a branch → 分支 main、目录 / (root) → Save
  4. 等待 1-2 分钟，刷新后顶部会出现网址

✅ 今天的成果网址：https://carlrowe.github.io/work-calendar/

把这个网址发给任何人，不用登录，打开就能用、数据全共享。

6以后想改功能怎么办？

想改网页的内容（加功能、改样式、调颜色），流程只有一步变：

  1. 把 index.html 更新成新的（可以让豆包帮你改好）
  2. 回到 GitHub 仓库 → 点文件 index.html → 点右上角铅笔图标编辑 → 把新内容整个粘贴进去 → Commit changes
  3. 等 1-2 分钟，网页自动更新，网址不变

数据不用动——数据都存在数据库里，改网页不影响数据。

8常见问题（FAQ）

问题答案
网页打不开 / 白屏？先确认 index.html 已上传、Pages 已开启；等 1-2 分钟再刷新。
打开后没数据 / 报错？99% 是忘了在 Supabase 跑建表代码，去 SQL Editor 再 Run 一次。
数据不共享 / 一人改别人看不到？确认数据库开了"匿名读写"权限（建表代码里的 policy 部分）。
怎么加新同事？打开网页 → 用户管理 → 添加用户。数据自动云端共享。
换手机/电脑数据还在吗？在！数据存在 Supabase 云端，任何设备打开都是最新。
担心公开钥匙被偷？公开钥匙本来就是给所有人用的，安全。管理员那把钥匙（service_role）才要保密。
